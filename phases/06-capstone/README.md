# Fase 6. Proyecto integrador

**Objetivo:** aplicar lo aprendido en una evaluación de seguridad completa de un entorno propio.

## Proyecto

| ID | Proyecto | Temas aplicados | Estado |
|----|----------|-----------------|:------:|
| EXP-040 | Evaluación de seguridad de un laboratorio propio | Reconocimiento, análisis de superficie de ataque, revisión de configuraciones, pruebas controladas, detección, mitigación e informe técnico | ⬜ |

## Entorno

- Una pequeña red virtual aislada.
- Un servidor Linux.
- Una aplicación web deliberadamente vulnerable.

## Entregable

El objetivo no es acumular exploits, sino producir un informe técnico reproducible que contenga:

1. Alcance definido.
2. Hallazgos.
3. Evidencias.
4. Impacto.
5. Correcciones.
6. Comprobaciones posteriores a la corrección.

## Resultado esperado

Un informe que otra persona pueda reproducir con el mismo entorno y llegar a los mismos hallazgos.
